Herramienta en fase beta. El script se ha probado con equipos simulados (PLC, OPC UA, SNMP, IoT Core). Antes de usarlo en una célula real, ejecútalo con --plan y revisa los resultados con espíritu crítico. Si algo no cuadra con lo que ves en el equipo, anótalo: es parte de la práctica.

Cómo ejecutar la verificación en la célula

Solo lectura y con permiso. El script consulta únicamente las IP de la línea base, con pausas entre consultas, y nunca escribe en los equipos. Aun así, ejecútalo con la instalación parada o en pruebas y con autorización del responsable. En OT, una consulta inoportuna también es un riesgo.

1 · Dónde se ejecuta

En un PC autorizado conectado a la VLAN de la célula (o con ruta hacia ella). El descubrimiento PROFINET DCP es de capa 2: solo funciona desde la misma VLAN y, en Windows, necesita Npcap.

2 · Preparación (una vez)

python --version          # Python 3.9 o superior
pip install python-snap7 asyncua netmiko pnio_dcp   # opcionales

Sin bibliotecas opcionales el script funciona igual: puertos, SNMP, web e IoT Core de ifm usan solo Python estándar. Lo que necesite una biblioteca ausente aparecerá como NO COMPROBABLE.

3 · Credenciales (nunca en el JSON)

# Windows (PowerShell)                 # Linux / Raspberry Pi
$env:OT_SSH_USER="admin"               export OT_SSH_USER=admin
$env:OT_SSH_PASS="********"            export OT_SSH_PASS='********'

El prefijo lo define el campo Variable de credenciales de cada equipo (OT_SSH, OT_IFM, OT_OPCUA…). Si no existe la variable, el script lo pregunta por teclado.

4 · Ejecución

python verificar_celda.py linea_base_celda.json --plan     # ver qué consultaría (no toca la red)
python verificar_celda.py linea_base_celda.json            # verificación real

Genera resultado_<celda>_<fecha>.json; cárgalo en la pestaña ③. Las copias de configuración de los switches se guardan en copias_config/ y la siguiente ejecución muestra qué líneas cambiaron.

5 · Automatizar (nivel avanzado)

# Raspberry Pi en la red de gestión, todos los días a las 06:30
30 6 * * * cd /home/pi/verif && python3 verificar_celda.py linea_base.json --si -o res_$(date +\%F).json
